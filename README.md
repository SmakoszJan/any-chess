Any Chess is a silly side project made to test how far the variations of rules of chess can be pushed.
Community selection of features happens irregularly on r/anarchychess. Contributions are welcome, but only
bugfixes/improvements, not game mechanics. That would defeat the point. In some cases (will be specified),
I will accept content contributions.

# Features

Just chess. Except no castling because that's boring. Game ends when king dies, rather than with checkmate. No drawing rules.
